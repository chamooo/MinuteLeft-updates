# Minute Left — Update Feed

This repository hosts the Sparkle update feed (`appcast.xml`) and signed release
binaries for [Minute Left](https://github.com/chamooo/MinuteLeft).

Source code is **not** here — it lives in a separate private repository.

## Download

The latest release is always available at:

- **Appcast:** https://chamooo.github.io/MinuteLeft-updates/appcast.xml
- **Latest ZIP:** see `releases/` directory

Existing installs receive updates automatically via Sparkle.
